## About Me

I'm a communication designer and developer interested in the intersection of **visual identity, digital experiences, and technology**.

From crafting a brand's visual language to designing interfaces and building responsive websites, I enjoy working across the creative and technical sides of a project. I use AI-assisted coding tools to explore ideas, streamline workflows, and turn concepts into functional products.
